# Билайн ИИ-игры от Пакмана — beta

Ветка `beta` предназначена для **тестирования и разработки новых возможностей** генератора до их переноса в основную ветку `main`.

## Для чего нужна beta

- Проверять экспериментальные функции и изменения.
- Разрабатывать новые возможности, например 3D-графику, новые игровые механики и варианты управления.
- Находить ошибки и исправлять их до выпуска в основную ветку.
- Проверять, что новые функции не ломают уже работающие возможности приложения.

## Как использовать ветку

1. Новые функции и экспериментальные изменения сначала добавляются в `beta`.
2. После изменений приложение проверяется: запуск, генерация игры, управление, переходы между этапами и другие затронутые функции.
3. После успешного тестирования проверенные изменения переносятся из `beta` в `main`.

## Важно

Ветка `beta` может содержать незавершённые функции и ошибки. Она предназначена для разработки и испытаний, а не для стабильной демонстрации. Основная ветка `main` должна оставаться более стабильной версией проекта.

Общее описание проекта и инструкции по запуску будут поддерживаться в README основной ветки.
