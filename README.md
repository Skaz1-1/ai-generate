# Билайн ИИ-игры от Пакмана

ИИ-генератор автономных HTML5-мини-игр по текстовому описанию. Проект создан для кейса хакатона Билайна.

Пользователь описывает идею игры, выбирает сложность и масштаб, а приложение обращается к Gemini и показывает полученную игру в окне предпросмотра. Сгенерированную игру можно скачать как отдельный HTML-файл.

## Возможности

- Генерация мини-игр по описанию на русском языке.
- Настройка сложности и масштаба игры.
- Поддержка основной и резервной моделей Gemini.
- Проверка структуры HTML и дополнительные проверки игровых уровней.
- Попытка автоматического исправления некоторых проблем с проходимостью.
- Предпросмотр игры, история версий и доработка существующей игры.
- Скачивание игры как автономного HTML-файла.
- Светлая и тёмная темы интерфейса.
- Серверная обработка запросов к Gemini: API-ключ не должен находиться в клиентском коде.

> Генерация зависит от доступности Gemini API, действующих квот и времени ответа модели. Автоматические проверки помогают находить часть ошибок, но не гарантируют безошибочную работу каждой созданной игры.

## Технологии

- React и TypeScript
- Vite
- Node.js и Express
- Google GenAI SDK (`@google/genai`)
- HTML5, CSS и JavaScript для создаваемых игр
- Node.js test runner через `tsx --test`

## Требования

- Node.js 22 или новее (рекомендуется актуальная LTS-версия)
- npm
- API-ключ Gemini с доступом к используемой модели

## Запуск локально

1. Склонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone https://github.com/Skaz1-1/ai-generate.git
   cd ai-generate
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Создайте в корне проекта файл `.env` рядом с `package.json` и добавьте свои настройки:

   ```dotenv
   GEMINI_API_KEY=вставьте_свой_API_ключ
   GEMINI_MODEL=gemini-3.8-flash
   GEMINI_FALLBACK_MODEL=gemini-3.6-flash
   ```

   Укажите модели, к которым у вашего API-ключа действительно есть доступ. Если выбранная модель недоступна, проверьте актуальные названия моделей и ограничения в документации Google Gemini API.

4. Запустите приложение в режиме разработки:

   ```bash
   npm run dev
   ```

5. Откройте адрес, указанный в терминале (обычно http://localhost:3000).

Остановить сервер можно сочетанием `Ctrl+C` в терминале.

## Как устроен проект

- `server.ts` — Express-сервер, API-эндпоинты генерации и изменения игр, обращения к Gemini и обработка ошибок.
- `src/App.tsx` — основная логика интерфейса, создание и изменение игр, предпросмотр и история версий.
- `src/utils/gameValidator.ts` — извлечение и базовая проверка HTML-кода игры.
- `src/utils/gameRuntimeGuard.ts` — защитный слой для запуска игр в изолированной среде.
- `src/utils/geminiFallback.ts` — логика обращения к резервной модели при предусмотренных типах ошибок.
- `src/utils/promptAdapter.ts` — адаптация пользовательского описания для генерации.
- `src/utils/solvability/` — дополнительные проверки игровых уровней и проходимости.

Созданные игры предназначены для запуска как самостоятельные HTML-файлы без внешних библиотек. Фактическая автономность зависит от кода, сгенерированного моделью, и проверок приложения.

## Безопасность

- Не добавляйте API-ключ в исходный код, README, скриншоты или публичные коммиты.
- Не публикуйте файл `.env`. Храните ключ только в локальных переменных окружения или в защищённых настройках среды развёртывания.
- Не используйте чужой API-ключ без разрешения.
- Не размещайте приложение публично без дополнительной проверки безопасности и настройки ограничений доступа.

## Ограничения

- Генерация может завершиться ошибкой из-за перегрузки API, квот, недоступности модели или превышения времени ожидания.
- Резервная модель помогает только тогда, когда она доступна и у неё остаётся достаточно времени для ответа.
- Автоматические тесты проверяют предусмотренные сценарии, но не заменяют ручную проверку каждой игры.

## Статус проекта

Учебный прототип для хакатона. Проект находится в разработке; надёжность результата зависит в том числе от внешнего API Gemini.
