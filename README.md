# Билайн ИИ-игры от Пакмана

ИИ-генератор браузерных HTML5-мини-игр по текстовому описанию. Проект создан для кейса хакатона Билайна.

Пользователь описывает идею игры, выбирает сложность и масштаб, а приложение отправляет запрос модели ИИ, проверяет полученный код и показывает игру в окне предпросмотра. Игру можно доработать и скачать как HTML-файл.

> **Текущее состояние:** приложение использует Gemini 3.6 Flash. Генерация зависит от доступности API, квот и времени ответа. Встроенный Пакман служит стартовым примером и не является результатом новой генерации. На момент подготовки проекта генерация может работать нестабильно.

## Возможности

- Генерация мини-игр по текстовому описанию на русском языке.
- Настройка сложности и масштаба игры.
- Предпросмотр игры, история версий и возможность запросить изменения.
- Скачивание результата в формате HTML.
- Светлая и тёмная темы интерфейса.
- Проверка структуры HTML и дополнительные проверки игровых уровней.
- Защитный слой для запуска игры в изолированном окне.
- Серверная обработка запросов к Gemini API; ключ не должен попадать в клиентский код.

Автоматические проверки помогают находить часть ошибок, но не гарантируют безошибочную работу каждой сгенерированной игры.

## Технологии

- React, TypeScript и Vite
- Node.js и Express
- Google GenAI SDK (`@google/genai`)
- HTML, CSS и JavaScript для создаваемых игр
- `tsx --test` для запуска тестов

## Требования

- Node.js 22 или новее (рекомендуется актуальная LTS-версия)
- npm
- API-ключ Gemini с доступом к используемой модели

## Запуск локально

1. Склонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone https://github.com/Skaz1-1/ai-generate.git
   cd ai-generate
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Создайте файл `.env` в корне проекта рядом с `package.json` и добавьте API-ключ:

   ```dotenv
   GEMINI_API_KEY=вставьте_свой_API_ключ
   ```

   Сейчас модель задаётся в `server.ts` как `gemini-3.6-flash`. Значения `GEMINI_MODEL` и `GEMINI_FALLBACK_MODEL` из окружения не переключают модель в текущей версии. Не публикуйте свой файл `.env` и не добавляйте API-ключ в коммиты.

4. Запустите приложение:

   ```bash
   npm run dev
   ```

5. Откройте адрес, указанный в терминале (обычно http://localhost:3000).

Остановить сервер можно сочетанием `Ctrl+C`.

## Архитектура

- `server.ts` — Express-сервер, API-эндпоинты генерации и изменения игр, запросы к Gemini и обработка ошибок.
- `src/App.tsx` — состояние интерфейса, история версий и управление генерацией.
- `src/components/` — компоненты интерфейса и игрового предпросмотра.
- `src/utils/gameValidator.ts` — извлечение и базовая проверка HTML игры.
- `src/utils/gameRuntimeGuard.ts` — подготовка кода для изолированного запуска.
- `src/utils/promptAdapter.ts` — адаптация пользовательского описания.
- `src/utils/gameParameters.ts` — определение параметров игры по описанию.
- `src/utils/solvability/` — дополнительные проверки структуры уровней и проходимости.

Проект стремится создавать автономные HTML-файлы без внешних библиотек. Фактическая автономность зависит от кода, сгенерированного моделью.

## Ветки

- `main` — основная, более стабильная версия проекта.
- `beta` — тестирование изменений и экспериментальных функций перед переносом в `main`.

## Текущие ограничения и планы

- Генерация может завершаться ошибкой из-за квот, перегрузки API, недоступности модели или превышения времени ожидания.
- В текущей версии используется одна модель — Gemini 3.6 Flash; резервная модель отключена.
- В дальнейшем планируется выбрать более доступную ИИ-модель, чтобы снизить зависимость от ограничений текущего API.
- Ветка `beta` предназначена в том числе для экспериментов с новыми игровыми возможностями, включая 3D-графику. Эти функции не следует считать готовыми, пока они не проверены.

Это учебный прототип для хакатона. Тесты и программные проверки не заменяют ручную проверку каждой игры.
